# AI Ops API Implementation Plan (#32)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Token-gated `/api/ops` routes that serve the AI Ops dashboard everything it draws: live-traffic metrics, evaluation runs and their comparison, traces with their spans, the labelling queue and labels, and judge calibration.

**Architecture:** The pieces, by file:
- `ai/ops.py`: an `OpsQueries` class with every read model and aggregate the dashboard needs, computed from the AI store. The frontend only draws.
- `ai/ops_api.py`: thin FastAPI routes. A dependency checks `X-Ops-Token` against `CSA_OPS_TOKEN` in constant time and hands the routes the queries.
- `main.py`: mounts the routes only when `CSA_OPS_TOKEN` is set.
- `backend/scripts/seed_ops_store.py`: writes deterministic demo data (three days of traffic, a regression and a fix between two runs, a judged run, a label). The tests use it now, and the dashboard's browser tests will use it in #33.

**Tech Stack:** Python 3.13, FastAPI, SQLite, pytest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-16-ai-platform-core-design.md` (AI Ops dashboard: the endpoint table and the token rule; Rollout step 5)

## Global Constraints

- Every `/api/ops` route answers 401 `{"reason": "ops-unauthorized"}` without an `X-Ops-Token` header equal to `CSA_OPS_TOKEN`. The comparison is constant-time (`hmac.compare_digest`).
- Without `CSA_OPS_TOKEN` set, no `/api/ops` route is mounted (404).
- With a token but no AI store (database off or unusable), the routes answer 503 `{"reason": "no-ai-store"}`, after the token check.
- Aggregates (percentiles, rates, counts, per-day series, comparisons, kappa) are computed in the backend.
- Live metrics count only traces with `source = "live"`. Evaluation traces never count as traffic.
- Percentiles use the nearest-rank method: the value at position ceil(q·n) of the sorted values.
- Comparing two runs compares each case's pass^k (passed every repeat). Comparing runs of different datasets is 422 `different-datasets`, and an unknown run is 404 `unknown-run`.
- Times in responses are ISO 8601 with a UTC offset (`datetime.isoformat()`). The trace-list cursor is opaque to the client.
- Question and answer text appear only where the store kept them: evaluation traces always, live traces only with `CSA_TRACE_CONTENT=1`.
- No new dependencies.

## Review Focus

1. **A wrong token that shares a prefix with the right one.** Expect 401, compared in constant time. A missing header gets the same 401 (not 422). Test in Task 4.
2. **`/api/ops/eval-runs/compare` declared after `/eval-runs/{run_id}`**, so "compare" is taken as a run id. Expect compare to work: it is declared first. Test in Task 4.
3. **Paging through traces while two have the same start time.** Expect no trace skipped or repeated, because the cursor carries the time and the id. Test in Task 1.
4. **A label for an answer that does not exist, or helpfulness 7.** Expect 404 `unknown-result` and 422, with nothing written. Test in Task 4.
5. **A run older than the window, or a recorded replay newer than the last live run.** Expect the KPI to compare the newest live run with the live run before it; a recorded run counts only when a dataset has no live runs. Test in Task 3.

"""Demo data for the AI Ops dashboard: three days of live traffic, two golden runs with a regression and a fix
between them, an adversarial run, a recorded replay, a judged run and one label.

The ops tests and the dashboard's browser tests use it. To see the dashboard without real traffic:
    uv run python backend/scripts/seed_ops_store.py --db backend/ops-demo.db
then start the portal with CSA_AI_DB=backend/ops-demo.db and CSA_OPS_TOKEN set.
"""

from __future__ import annotations

import argparse
import sys
from datetime import UTC, datetime, timedelta
from pathlib import Path
from typing import Any

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

from csa_portal.ai.store import AiStore, EvalResultRecord, EvalRunRecord, LabelRecord, SpanRecord, TraceRecord  # noqa: E402

MODEL = "qwen/qwen3.8-27b"
# hours ago, duration ms, status, error reason, tokens in, tokens out, tool calls [(name, status)]
LIVE = [
    (1, 8000.0, "ok", None, 300, 40, [("find_place", "ok"), ("get_section_facts", "ok")]),
    (2, 12000.0, "ok", None, 320, 60, [("get_section_facts", "ok")]),
    (5, 30000.0, "error", "tool-limit", 900, 30, [("get_section_facts", "error")] * 3),
    (20, 9000.0, "ok", None, 280, 50, []),
    (30, 3000.0, "error", "assistant-unavailable", None, None, []),
    (60, 15000.0, "ok", None, 310, 70, [("get_crop_calendar", "ok")]),
]
# key, dataset, age, mode, model, judge, commit, [(case, passed)], keeps traces
RUNS = [
    ("a", "golden", timedelta(days=2), "live", MODEL, None, "aaa1111",
     [("case-a", True), ("case-b", True), ("case-c", False)], False),
    ("b", "golden", timedelta(days=1), "live", MODEL, "gemma", "bbb2222",
     [("case-a", True), ("case-b", False), ("case-c", True), ("case-d", False)], True),
    ("c", "adversarial", timedelta(days=1), "live", MODEL, None, "bbb2222",
     [("inject-a", True), ("inject-b", True)], False),
    ("r", "golden", timedelta(hours=1), "recorded", "cassette-replay", None, "bbb2222",
     [("case-a", True), ("case-b", False), ("case-c", True), ("case-d", False)], False),
]
FAITHFUL = {"case-a": 1.0, "case-b": 0.0, "case-c": 1.0, "case-d": None}


def ident(prefix: str, number: int, width: int = 32) -> str:
    return f"{prefix}{number:0{width - len(prefix)}d}"


def seed(store: AiStore, now: datetime) -> dict[str, Any]:
    ids: dict[str, Any] = {"live": [], "runs": {}, "results": {}}
    for n, (hours, duration, status, error, tokens_in, tokens_out, tools) in enumerate(LIVE):
        trace_id, started = ident("live", n), now - timedelta(hours=hours)
        root = ident(f"s{n}", 0, 16)
        usage = {k: v for k, v in (("gen_ai.usage.input_tokens", tokens_in), ("gen_ai.usage.output_tokens", tokens_out)) if v}
        spans = [
            SpanRecord(root, trace_id, None, "agent", "assistant", started, duration - 10, status,
                       {"gen_ai.agent.name": "assistant"}),
            SpanRecord(ident(f"s{n}", 1, 16), trace_id, root, "llm", f"chat {MODEL}", started + timedelta(milliseconds=1),
                       duration / 2, "error" if error == "assistant-unavailable" else "ok",
                       {"gen_ai.request.model": MODEL, **usage}),
        ]
        for k, (tool, tool_status) in enumerate(tools, start=2):
            spans.append(SpanRecord(ident(f"s{n}", k, 16), trace_id, root, "tool", tool,
                                    started + timedelta(milliseconds=k), 40.0, tool_status, {"gen_ai.tool.name": tool}))
        store.write_trace(TraceRecord(trace_id, "live", "assistant", MODEL, started, duration, status, error,
                                      tokens_in, tokens_out, "f" * 64, None, None, None, spans))
        ids["live"].append(trace_id)

    for key, dataset, age, mode, model, judge, commit, cases, keeps_traces in RUNS:
        run_id, started = ident(f"run{key}", 0), now - age
        results = []
        for i, (case_id, passed) in enumerate(cases):
            trace_id = None
            if keeps_traces:
                trace_id = ident(f"eval{key}", i)
                store.write_trace(TraceRecord(trace_id, "eval", "assistant", model, started + timedelta(seconds=i),
                                              9000.0, "ok", None, 300, 40, "f" * 64, f"Question for {case_id}",
                                              f"Answer for {case_id}", run_id))
            scores: dict[str, Any] = {"required_terms": {
                "value": 1.0 if passed else 0.0, "passed": passed, "reason": "all terms present" if passed else "missing: Punjab",
            }}
            if judge:
                value = FAITHFUL[case_id]
                scores["faithfulness"] = {"value": value, "passed": None,
                                          "reason": "judge-unavailable" if value is None else "faithful" if value else "unfaithful"}
            results.append(EvalResultRecord(ident(f"res{key}", i), run_id, case_id, 0, trace_id, passed, scores))
        passed_cases = sum(passed for _, passed in cases)
        summary: dict[str, Any] = {
            "cases": len(cases), "repeats": 1, "passed_cases": passed_cases, "pass_rate": passed_cases / len(cases),
            "flaky_cases": [], "scorers": {"required_terms": passed_cases / len(cases)},
        }
        if judge:
            summary["judge"] = {"model": judge, "calibrated": False, "faithful_rate": 2 / 3, "mean_helpfulness": None,
                                "unavailable": 1}
        store.write_eval_run(EvalRunRecord(run_id, started, started + timedelta(minutes=10), commit, dataset, 2, mode,
                                           model, judge, 1, "partial" if judge else "complete", summary), results)
        ids["runs"][key] = run_id
        ids["results"][key] = {r.case_id: r.id for r in results}

    store.write_label(LabelRecord(ident("label", 0), ids["results"]["b"]["case-a"], "officer", True, 4,
                                  "Right figures.", now - timedelta(hours=20)))
    return ids


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("--db", type=Path, required=True, help="a new database file to fill")
    args = parser.parse_args(argv)
    if args.db.exists():
        parser.error(f"{args.db} exists; give a new file")
    seed(AiStore(args.db), datetime.now(UTC))
    print(f"Seeded {args.db}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

"""Read models for the AI Ops dashboard, computed from the AI store: live traffic, evaluation runs and their
comparison, traces, labels and judge calibration. The dashboard only draws what these return."""

from __future__ import annotations

import json
import math
import secrets
from collections import Counter
from collections.abc import Callable
from dataclasses import asdict
from datetime import UTC, datetime, timedelta
from typing import Any

from .evals.calibration import calibration
from .store import AiStore, LabelRecord, _stamp, _time

_TRACE_FIELDS = (
    "id", "source", "agent", "model", "started_at", "duration_ms", "status", "error_reason", "input_tokens",
    "output_tokens", "eval_run_id",
)


class OpsQueries:
    def __init__(self, store: AiStore, now: Callable[[], datetime] = lambda: datetime.now(UTC)) -> None:
        self.store = store
        self.now = now

    def traces(
        self, *, source: str | None = None, agent: str | None = None, status: str | None = None,
        before: str | None = None, limit: int = 50,
    ) -> dict[str, Any]:
        """Traces newest first. `next` is the cursor for the page after this one: the last trace's start and id."""
        clauses, params = [], []
        for column, value in (("source", source), ("agent", agent), ("status", status)):
            if value:
                clauses.append(f"{column} = ?")
                params.append(value)
        if before:
            started, _, trace_id = before.partition("|")
            clauses.append("(started_at < ? OR (started_at = ? AND id < ?))")
            params += [started, started, trace_id]
        where = f"WHERE {' AND '.join(clauses)}" if clauses else ""
        rows = self.store.read(
            f"SELECT {', '.join(_TRACE_FIELDS)} FROM traces {where} ORDER BY started_at DESC, id DESC LIMIT ?",
            (*params, limit + 1),
        )
        page = rows[:limit]
        items = [{**dict(zip(_TRACE_FIELDS, row)), "started_at": _time(row[4]).isoformat()} for row in page]
        return {"traces": items, "next": f"{page[-1][4]}|{page[-1][0]}" if len(rows) > limit else None}

    def trace(self, trace_id: str) -> dict[str, Any] | None:
        record = self.store.get_trace(trace_id)
        return None if record is None else _jsonable(asdict(record))


def _jsonable(node: Any) -> Any:
    if isinstance(node, datetime):
        return node.isoformat()
    if isinstance(node, dict):
        return {key: _jsonable(value) for key, value in node.items()}
    if isinstance(node, list):
        return [_jsonable(item) for item in node]
    return node
```

    def eval_runs(self, dataset: str | None = None, limit: int = 50) -> list[dict[str, Any]]:
        where, params = ("WHERE dataset = ?", (dataset,)) if dataset else ("", ())
        rows = self.store.read(
            f"SELECT {', '.join(_RUN_FIELDS)} FROM eval_runs {where} ORDER BY started_at DESC, id DESC LIMIT ?",
            (*params, limit),
        )
        return [_run(row) for row in rows]

    def eval_run(self, run_id: str) -> dict[str, Any] | None:
        found = self.store.get_eval_run(run_id)
        if found is None:
            return None
        run, results = found
        return {"run": _jsonable(asdict(run)), "results": [asdict(result) for result in results]}

    def compare(self, a: str, b: str) -> dict[str, Any]:
        """Case by case, `a` (before) against `b` (after); a case passed when it passed every repeat."""
        found = {run_id: self.store.get_eval_run(run_id) for run_id in (a, b)}
        for run_id, value in found.items():
            if value is None:
                raise LookupError(run_id)
        (run_a, results_a), (run_b, results_b) = found[a], found[b]
        if run_a.dataset != run_b.dataset:
            raise ValueError("different-datasets")
        before, after = _pass_k(results_a), _pass_k(results_b)
        both = before.keys() & after.keys()
        return {
            "a": _jsonable(asdict(run_a)),
            "b": _jsonable(asdict(run_b)),
            "regressions": sorted(c for c in both if before[c] and not after[c]),
            "fixes": sorted(c for c in both if not before[c] and after[c]),
            "still_failing": sorted(c for c in both if not before[c] and not after[c]),
            "new_cases": sorted(after.keys() - before.keys()),
            "removed_cases": sorted(before.keys() - after.keys()),
        }
```

    def metrics(self, window: str = "24h") -> dict[str, Any]:
        if window not in WINDOWS:
            raise ValueError(f"unknown window {window}")
        since = self.now() - WINDOWS[window]
        return {
            "window": window,
            "since": since.isoformat(),
            "live": self._live(since),
            "eval": self._evaluation(),
            "calibration": self.calibration(),
        }

    def _live(self, since: datetime) -> dict[str, Any]:
        rows = self.store.read(
            "SELECT started_at, duration_ms, status, error_reason, input_tokens, output_tokens FROM traces "
            "WHERE source = 'live' AND started_at >= ?", (_stamp(since),),
        )
        durations = sorted(row[1] for row in rows)
        errors = [row for row in rows if row[2] == "error"]
        days: dict[str, dict[str, Any]] = {}
        for started, _, status, *_ in rows:
            day = days.setdefault(started[:10], {"day": started[:10], "requests": 0, "errors": 0})
            day["requests"] += 1
            day["errors"] += status == "error"
        reasons = Counter(row[3] or "unknown" for row in errors)
        tool_rows = self.store.read(
            "SELECT s.name, s.status FROM spans s JOIN traces t ON t.id = s.trace_id "
            "WHERE t.source = 'live' AND t.started_at >= ? AND s.kind = 'tool'", (_stamp(since),),
        )
        tools: dict[str, dict[str, Any]] = {}
        for name, status in tool_rows:
            tool = tools.setdefault(name, {"tool": name, "calls": 0, "errors": 0})
            tool["calls"] += 1
            tool["errors"] += status == "error"
        return {
            "requests": len(rows),
            "errors": len(errors),
            "error_rate": len(errors) / len(rows) if rows else None,
            "p50_latency_ms": _percentile(durations, 0.5),
            "p95_latency_ms": _percentile(durations, 0.95),
            "input_tokens": _sum(row[4] for row in rows),
            "output_tokens": _sum(row[5] for row in rows),
            "by_day": [days[day] for day in sorted(days)],
            "error_reasons": [{"reason": r, "count": c} for r, c in sorted(reasons.items(), key=lambda i: (-i[1], i[0]))],
            "tools": sorted(tools.values(), key=lambda t: (-t["calls"], t["tool"])),
        }

    def _evaluation(self) -> dict[str, Any]:
        rows = self.store.read(
            "SELECT id, dataset, mode, model, judge_model, git_sha, started_at, status, summary FROM eval_runs "
            "ORDER BY started_at DESC, id DESC LIMIT 200"
        )
        history = []
        for run_id, dataset, mode, model, judge, sha, started, status, summary_text in reversed(rows):
            summary = json.loads(summary_text)
            history.append({
                "run_id": run_id, "dataset": dataset, "mode": mode, "model": model, "judge_model": judge,
                "git_sha": sha, "started_at": _time(started).isoformat(), "status": status,
                "pass_rate": summary.get("pass_rate"), "scorers": summary.get("scorers", {}), "judge": summary.get("judge"),
            })
        latest = []
        for dataset in sorted({run["dataset"] for run in history}):
            runs = [run for run in history if run["dataset"] == dataset]
            # The KPI follows live runs; a recorded replay counts only when a dataset has no live run yet.
            pool = [run for run in runs if run["mode"] == "live"] or runs
            previous = pool[-2]["pass_rate"] if len(pool) > 1 else None
            latest.append({**pool[-1], "previous_pass_rate": previous})
        return {"latest": latest, "history": history}

    def calibration(self) -> list[dict[str, Any]]:
        models = self.store.read(
            "SELECT DISTINCT judge_model FROM eval_runs WHERE judge_model IS NOT NULL ORDER BY judge_model"
        )
        states = []
        for (model,) in models:
            state = calibration(self.store.calibration_pairs(model))
            states.append({"judge_model": model, "labels": state.labels, "kappa": state.kappa,
                           "calibrated": state.calibrated, "confusion": state.confusion})
        return states

    def label_queue(self, limit: int = 20) -> list[dict[str, Any]]:
        return [asdict(item) for item in self.store.unlabelled_results(limit)]

    def add_label(self, result_id: str, labeller: str, faithful: bool, helpful: int | None, note: str) -> str:
        label_id = secrets.token_hex(16)
        self.store.write_label(LabelRecord(label_id, result_id, labeller, faithful, helpful, note, self.now()))
        return label_id
```

def _percentile(values: list[float], q: float) -> float | None:
    """Nearest rank: the value at position ceil(q * n) of the sorted values."""
    return values[max(0, math.ceil(q * len(values)) - 1)] if values else None


def _sum(values: Any) -> int | None:
    known = [value for value in values if value is not None]
    return sum(known) if known else None

```python
"""The AI Ops API (/api/ops) the dashboard reads. Every route needs an X-Ops-Token header equal to CSA_OPS_TOKEN;
without CSA_OPS_TOKEN set, main.py does not mount these routes at all."""

from __future__ import annotations

import hmac
from collections.abc import Callable
from datetime import UTC, datetime
from typing import Annotated, Any, Literal

from fastapi import APIRouter, Depends, FastAPI, Header, HTTPException, Query
from pydantic import BaseModel, Field

from .ops import OpsQueries
from .store import AiStore


class LabelIn(BaseModel):
    result_id: str = Field(min_length=1, max_length=64)
    labeller: str = Field(min_length=1, max_length=80)
    faithful: bool
    helpful: int | None = Field(default=None, ge=1, le=5)
    note: str = Field(default="", max_length=1000)


def _error(status: int, reason: str, message: str) -> HTTPException:
    return HTTPException(status, detail={"reason": reason, "message": message})


def add_ops_routes(
    app: FastAPI, token: str, store: AiStore | None, now: Callable[[], datetime] = lambda: datetime.now(UTC)
) -> None:
    queries = OpsQueries(store, now) if store is not None else None

    def ops(x_ops_token: Annotated[str | None, Header()] = None) -> OpsQueries:
        # Checked before anything else, in constant time, so a wrong token learns nothing.
        if x_ops_token is None or not hmac.compare_digest(x_ops_token.encode(), token.encode()):
            raise _error(401, "ops-unauthorized", "A valid X-Ops-Token header is required")
        if queries is None:
            raise _error(503, "no-ai-store", "The AI store is not available; see /api/health")
        return queries

    Ops = Annotated[OpsQueries, Depends(ops)]
    router = APIRouter(prefix="/api/ops", tags=["AI Ops"])

    @router.get("/metrics")
    def metrics(ops: Ops, window: Literal["24h", "7d", "30d"] = "24h") -> dict[str, Any]:
        return ops.metrics(window)

    @router.get("/eval-runs")
    def eval_runs(ops: Ops, dataset: str | None = None, limit: Annotated[int, Query(ge=1, le=200)] = 50) -> dict[str, Any]:
        return {"runs": ops.eval_runs(dataset, limit)}

    # Declared before /eval-runs/{run_id}, which would otherwise take "compare" as a run id.
    @router.get("/eval-runs/compare")
    def compare(ops: Ops, a: str, b: str) -> dict[str, Any]:
        try:
            return ops.compare(a, b)
        except LookupError as error:
            raise _error(404, "unknown-run", f"No evaluation run {error}") from error
        except ValueError as error:
            raise _error(422, "different-datasets", "Only runs of the same dataset can be compared") from error

    @router.get("/eval-runs/{run_id}")
    def eval_run(ops: Ops, run_id: str) -> dict[str, Any]:
        found = ops.eval_run(run_id)
        if found is None:
            raise _error(404, "unknown-run", f"No evaluation run {run_id}")
        return found

    @router.get("/traces")
    def traces(
        ops: Ops,
        source: Literal["live", "eval"] | None = None,
        agent: str | None = None,
        status: Literal["ok", "error"] | None = None,
        before: str | None = None,
        limit: Annotated[int, Query(ge=1, le=200)] = 50,
    ) -> dict[str, Any]:
        return ops.traces(source=source, agent=agent, status=status, before=before, limit=limit)

    @router.get("/traces/{trace_id}")
    def trace(ops: Ops, trace_id: str) -> dict[str, Any]:
        found = ops.trace(trace_id)
        if found is None:
            raise _error(404, "unknown-trace", f"No trace {trace_id}")
        return found

    @router.get("/labels/queue")
    def label_queue(ops: Ops, limit: Annotated[int, Query(ge=1, le=100)] = 20) -> dict[str, Any]:
        return {"queue": ops.label_queue(limit)}

    @router.post("/labels", status_code=201)
    def add_label(ops: Ops, body: LabelIn) -> dict[str, str]:
        try:
            return {"id": ops.add_label(body.result_id, body.labeller, body.faithful, body.helpful, body.note)}
        except ValueError as error:
            if "unknown result" in str(error):
                raise _error(404, "unknown-result", str(error)) from error
            raise _error(422, "bad-label", str(error)) from error

    @router.get("/calibration")
    def judge_calibration(ops: Ops) -> dict[str, Any]:
        return {"judges": ops.calibration()}

    app.include_router(router)
```
